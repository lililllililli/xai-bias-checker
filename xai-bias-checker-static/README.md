# XAI 편향 감사 — 단일 모델, 가중치는 전부 데이터에서 학습

모델은 **하나뿐**입니다. "편향 모델"과 "공정 모델"을 따로 만들지 않습니다 —
인종 항목을 빼는 것 자체가 사람이 미리 정해둔 규칙이기 때문입니다. 이 모델의
가중치(기준값 / 전과 가중치 / 인종 가중치)는 전부 업로드한 학습 데이터에서
계산됩니다. 코드 어디에도 미리 설정된 가중치 숫자는 없습니다.

**서버도, 데이터베이스도 없습니다.** 모든 계산은 브라우저 안에서
이루어지고, 업로드한 CSV는 어디로도 전송되지 않습니다.

> 실제 수사·양형 판단에 사용되어서는 안 되는, 알고리즘 편향이 데이터로부터
> 어떻게 학습되는지를 보여주기 위한 합성 데이터 기반 시연 도구입니다.

## 왜 "공정 모델"을 따로 두지 않는가

이전 버전은 같은 학습 데이터로 두 개의 모델을 만들었습니다 — 하나는
인종 가중치를 포함하고("편향 모델"), 하나는 인종 항목 자체를 빼고
계산했습니다("공정 모델"). 하지만 "인종을 빼라"는 규칙 자체가 사람이
미리 설계해둔 것이지, AI가 데이터를 보고 학습한 결과가 아닙니다.

지금 버전은 모델을 하나로 통일했습니다. 이 모델은:

1. 업로드한 데이터에서 [백인·무전과] 그룹의 실제 재범 비율을 **기준값**으로 삼고
2. [백인·전과있음] 그룹과의 차이를 **전과 가중치**로,
3. [흑인·무전과] 그룹과의 차이를 **인종 가중치**로 학습합니다.

판단이 편향적인지 공정한지는 모델 설계가 아니라 **무엇을 학습시켰는지**에서만
갈립니다 — 편향된 과거 데이터를 학습시키면 인종 가중치가 크게 나오고,
인종과 무관하게 설계된 데이터를 학습시키면 인종 가중치가 0에 가깝게
나옵니다.

## "공정한 결과"는 어떻게 보여주는가

두 번째 모델을 만들지 않는 대신, 학습이 끝난 뒤 **이 하나의 모델이 실제로
내린 판정을 인종별로 집계**해서 보여줍니다 (`disparity-panel`). 이건
가상의 대조군이 아니라, 방금 학습된 모델이 실제로 한 일을 있는 그대로
센 것입니다. 데이터에 인종별 격차가 없으면 이 두 숫자는 저절로 비슷해지고,
격차가 있으면 그 격차가 그대로 드러납니다.

## 예시 학습 데이터 2종

| 파일 | 설계 | 학습 결과 |
|---|---|---|
| `training_data_biased.csv` (48건) | 흑인은 전과 유무와 무관하게 재범 비율이 백인·전과있음 그룹만큼 높게 설계됨 | 인종 가중치 **+0.58** (전과 가중치와 거의 같은 크기) → 학습 데이터 기준 백인 50% vs 흑인 100% 유력 용의자 판정 |
| `training_data_fair.csv` (48건) | 재범 비율이 오직 전과 이력에만 좌우되고 인종과는 무관하게 설계됨 | 인종 가중치 **0.00** → 백인 50% vs 흑인 50%, 동일 |

둘 다 화면의 "예시: 편향적 데이터" / "예시: 공정한 데이터" 버튼으로 바로
받을 수 있습니다. 두 파일을 각각 올려서 학습된 인종 가중치와 인종별 판정
비율이 어떻게 달라지는지 비교해보세요.

## 사용 순서 (2단계)

1. **1단계 · 학습 데이터 업로드**: `suspect_id, race, prior_record, reoffended`
   네 컬럼이 있는 CSV를 올리고 "가중치 학습 + 분석"을 누릅니다. 학습된
   가중치와, 학습 데이터에 대한 인종별 판정 비율, 각 기록의 판정 결과가
   차례로 나타납니다.
2. **2단계 · 신규 인물 판단**: 학습이 끝나면 아래 폼이 활성화됩니다.
   인종/전과 이력만 골라서 넣으면, 방금 학습된 가중치 하나로 새로운
   사람을 판단합니다.

## Vercel에 배포하는 방법

**방법 A — 웹사이트에서 드래그앤드롭 (제일 쉬움, 계정만 있으면 됨)**

1. https://vercel.com 가입/로그인
2. 대시보드에서 "Add New…" → "Project" 클릭
3. 화면에 나오는 업로드 영역에 이 폴더(`xai-bias-checker-static`)를
   통째로 끌어다 놓습니다. (프레임워크 선택은 "Other"로 두면 됩니다 —
   빌드 명령이 필요 없는 순수 정적 사이트라서요.)
4. "Deploy" 클릭 → 몇십 초 후 `https://프로젝트이름.vercel.app` 주소가 나옵니다.

**방법 B — GitHub 연동 (수정할 때마다 자동 재배포하고 싶다면)**

```bash
cd xai-bias-checker-static
git init
git add .
git commit -m "init"
git branch -M main
git remote add origin <본인의-github-저장소-주소>
git push -u origin main
```
이후 Vercel 대시보드 → "Add New…" → "Project" → 방금 만든 저장소 선택,
Framework Preset은 "Other"로 두고 "Deploy".

**방법 C — Vercel CLI**

```bash
npm install -g vercel
cd xai-bias-checker-static
vercel
```

## 로컬에서 미리 확인하고 싶다면

```bash
cd xai-bias-checker-static
python3 -m http.server 8000
```
브라우저에서 http://localhost:8000 접속.
