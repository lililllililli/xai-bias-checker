# XAI 편향 감사 — 정적 사이트 버전 (가중치는 데이터에서 학습)

과거 기록(실제 재범 여부 포함)을 올리면, 그 데이터 안에서 전과 이력과
인종 각각이 결과와 얼마나 관련 있었는지를 계산해 **가중치를 그 자리에서
학습**합니다. 그렇게 학습된 가중치로 "편향 모델"(인종 포함)과 "공정
모델"(인종 제외)이 새로운 사람을 각각 어떻게 판단하는지 비교합니다.

**서버도, 데이터베이스도 없습니다.** 모든 계산은 브라우저 안에서
이루어지고, 업로드한 CSV는 어디로도 전송되지 않습니다.

> 실제 수사·양형 판단에 사용되어서는 안 되는, 알고리즘 편향이 데이터로부터
> 어떻게 학습되는지를 보여주기 위한 합성 데이터 기반 시연 도구입니다.

## 가중치를 더 이상 고정하지 않는 이유

이전 버전은 "전과 가중치 2.0, 인종 가중치 1.7"처럼 개발자가 미리 정해둔
숫자를 썼습니다. 그런데 이건 사람이 규칙을 직접 정한 것이지, AI가 데이터를
보고 학습한 게 아닙니다. 지금 버전은 업로드한 CSV 안에서:

1. **기준값** = [백인 · 무전과] 그룹의 실제 재범 비율
2. **전과 가중치** = [백인 · 전과있음] 그룹의 재범 비율 − 기준값
3. **인종 가중치** = [흑인 · 무전과] 그룹의 재범 비율 − 기준값

이렇게 그룹별 비율 차이로 가중치를 계산합니다. 데이터 자체에 인종별
격차가 없으면 인종 가중치는 0에 가깝게 학습되고, 과거 기록에 이미 격차가
있었다면 그 격차가 그대로 가중치에 반영됩니다 — 즉 편향이 "설계"되는 게
아니라 "데이터로부터 학습"된다는 것을 보여줍니다.

## 예시 학습 데이터 2종

| 파일 | 내용 |
|---|---|
| `training_data_biased.csv` | 흑인 그룹의 재범 비율이 전과 이력과 무관하게 백인보다 높게 설계된 데이터 (48건). 학습하면 인종 가중치가 뚜렷하게 나옵니다. |
| `training_data_fair.csv` | 재범 비율이 오직 전과 이력에만 좌우되고 인종과는 무관하게 설계된 데이터 (48건). 학습하면 인종 가중치가 0에 가깝게 나옵니다. |

둘 다 화면의 "예시: 편향적 데이터" / "예시: 공정한 데이터" 버튼으로 바로
받을 수 있습니다. 두 파일을 각각 올려서 학습된 가중치가 어떻게 달라지는지
비교해보세요.

## 사용 순서 (2단계)

1. **1단계 · 학습 데이터 업로드**: `suspect_id, race, prior_record, reoffended`
   네 컬럼이 있는 CSV를 올리고 "가중치 학습 + 분석"을 누릅니다. 학습된
   가중치(기준값/전과 가중치/인종 가중치)와, 학습에 쓰인 각 기록에 대한
   편향 모델·공정 모델 판단이 아래에 나타납니다.
2. **2단계 · 신규 인물 판단**: 학습이 끝나면 아래 폼이 활성화됩니다.
   인종/전과 이력만 골라서 넣으면, 방금 학습된 가중치로 새로운 사람을
   즉시 판단합니다.

## Vercel에 배포하는 방법

**방법 A — 웹사이트에서 드래그앤드롭 (제일 쉬움, 계정만 있으면 됨)**

1. https://vercel.com 가입/로그인
2. 대시보드에서 "Add New…" → "Project" 클릭
3. 화면에 나오는 업로드 영역에 이 폴더(`xai-bias-checker-static`)를
   통째로 끌어다 놓습니다. (프레임워크 선택은 "Other"로 두면 됩니다 —
   빌드 명령이 필요 없는 순수 정적 사이트라서요.)
4. "Deploy" 클릭 → 몇십 초 후 `https://프로젝트이름.vercel.app` 주소가 나옵니다.

**방법 B — GitHub 연동 (수정할 때마다 자동 재배포하고 싶다면)**

1. 이 폴더를 새 GitHub 저장소에 올립니다.
   ```bash
   cd xai-bias-checker-static
   git init
   git add .
   git commit -m "init"
   git branch -M main
   git remote add origin <본인의-github-저장소-주소>
   git push -u origin main
   ```
2. Vercel 대시보드 → "Add New…" → "Project" → 방금 만든 저장소 선택
3. Framework Preset은 "Other" 선택 (Build Command, Output Directory 비워둠)
4. "Deploy" 클릭

**방법 C — Vercel CLI (터미널이 편하다면)**

```bash
npm install -g vercel
cd xai-bias-checker-static
vercel
```
질문에 답하면서 진행하면 되고, 마지막에 배포 URL이 출력됩니다.
이후 수정하고 다시 배포할 땐 `vercel --prod`.

## 로컬에서 미리 확인하고 싶다면

```bash
cd xai-bias-checker-static
python3 -m http.server 8000
```
브라우저에서 http://localhost:8000 접속.

